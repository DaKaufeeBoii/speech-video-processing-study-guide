Slide 4: Fast Fourier Transform (FFT) // Speech signals are continuous, time-varying signals that carry information in both time and frequency domains. // The Fast Fourier Transform (FFT) converts speech signals from the time domain to the frequency domain efficiently. // This transformation helps in analyzing important speech features such as pitch, formants, and signal energy distribution. // FFT is widely used as a fundamental step in speech recognition and feature extraction techniques .
Slide 5: Why FFT in Speech Recognition // Speech signals consist of multiple overlapping frequency components // FFT is used to convert speech into the frequency (spectral) domain for analysis // Key Functions of FFT: // Identifies dominant frequency components in speech signals
Slide 6: Property 1 – Linearity // FFT is a linear transformation, meaning it preserves addition and scaling of signals . // Mathematical Representation: // If two signals are combined in time domain:x₁(t) + x₂(t)then their FFT becomes:X₁(f) + X₂(f) // Key Idea:
Slide 7: Property 2 – Symmetry // Speech signals are real-valued signals in the time domain // The FFT of a real signal exhibits conjugate symmetry in the frequency domain // Key Property: // The spectrum satisfies: Positive frequencies are the complex conjugate mirror of negative frequencies
Slide 8: Property 3 – Time Shifting // When a speech signal is shifted in time, its frequency characteristics follow a specific behavior . // Key Property: // If a signal is delayed or advanced in time: // The magnitude spectrum remains unchanged
Slide 9: Property 4 – Frequency Resolution // Frequency resolution refers to the ability of FFT to distinguish closely spaced frequency components // It is directly dependent on the number of FFT points (N) // Key Relationship: // Higher FFT size (N) → better frequency resolution
Slide 10: Property 5 – Energy Conservation (Parseval’s Theorem) // Parseval’s Theorem states that energy is preserved in both time and frequency domains // The total energy of a signal remains constant after applying FFT // Key Concept: // Energy in time domain = Energy in frequency domain
Slide 11: Property 6 – Periodicity Assumption // FFT assumes that the input signal is periodic and continuous in nature // However, real-world speech signals are non-periodic and time-varying // Key Issue: // Direct FFT on speech may cause spectral discontinuities (edge effects)
Slide 12: Applications in Speech Recognition // FFT plays a key role in converting speech signals into useful frequency-domain features // Major Applications: // Feature Extraction // Used in generating MFCC and Spectrogram features

Slide 2: Role of Static and Dynamic Features in Speech Processing // In speech processing, features are extracted from speech signals to represent useful information for tasks like speech recognition and speaker identification. // These features are broadly classified into static and dynamic features.
Slide 3: Static Features // Static features represent the instantaneous characteristics of the speech signal at a particular time frame. They capture the spectral properties of speech. // Examples: MFCC (Mel-Frequency Cepstral Coefficients), LPC (Linear Predictive Coefficients) // Provide information about vocal tract shape // Useful for identifying phonemes (basic sound units)
Slide 4: Dynamic Features // Dynamic features represent the temporal variations of speech over time. They are derived from static features. // Types: // Delta (Δ) features – First-order derivative (rate of change) // Delta-Delta (Δ²) features – Second-order derivative (acceleration)
Slide 5: Role and Importance // Static features alone cannot capture speech variations over time // Dynamic features add contextual and temporal information // Combined use enhances accuracy in systems like Automatic Speech Recognition (ASR) // Both static and dynamic features are essential. Static features describe what the speech is, while dynamic features describe how speech changes over time, leading to better performance in speech processing applications.
